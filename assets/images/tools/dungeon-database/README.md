# 副本圖片目錄

此目錄原本預留給副本的封面圖片。副本資料庫頁面目前不顯示副本圖片，這裡也沒有任何圖片檔（見「目前的狀況」）；以下的命名與規格，是以後要把圖片放回來時用的。

## 檔案命名規則

圖片檔案應該按照副本的ID命名：
- 格式：`{id}.jpg`
- 範例：`1.jpg`, `2.jpg`, `362.jpg`

## 圖片規格建議

- **格式**：JPG
- **尺寸**：建議 400x200 像素或以上
- **比例**：2:1 (寬:高)
- **檔案大小**：建議小於 200KB

## 副本ID對應表

| ID範圍 | 內容 |
|--------|------|
| 1-100 | 四人迷宮 |
| 101-362 | 各種大型任務、討伐戰、絕境戰等 |

## 圖片來源

建議從以下來源獲取副本圖片：
- Final Fantasy XIV官方截圖
- 遊戲內副本選擇畫面截圖
- 社群分享的高品質副本圖片

## 目前的狀況

副本資料庫頁面（`tools/dungeon-database/`）目前不顯示副本圖片：列表一列一個副本，只有文字，頁面不會讀這個目錄裡的檔案。`data/dungeons.json` 每一筆的 `image` 欄位（例如 `images/362.jpg`）保留著，但沒有用到，新增副本時請設為 `null`。要把圖片放回頁面，需要先改 `tools/dungeon-database/` 的頁面（`index.html`、`script.js`、`style.css`）。

## 注意事項

- 所有圖片都應該符合著作權使用規範
- 建議使用 WebP 或 JPG 格式以獲得最佳效能
- 圖片應該清晰且具有代表性
