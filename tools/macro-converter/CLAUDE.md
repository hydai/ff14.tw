# 巨集轉換器（tools/macro-converter/）

把英文、日文攻略裡的生產巨集換成繁體中文（目標語言也可以選英文、日文）。這裡只記讀程式碼看不出來的原因與陷阱。

- 範圍只有生產技能與文字指令：`data/macro-mappings.json` 只有這些，戰鬥、採集技能還沒收錄，頁面上寫明。
- 遊戲沒有註解的寫法：不是 `/` 開頭的行（貼上的標題、表格複製下來的編號、`#` 備註）會被送到聊天，所以整行照原文留著並列成要注意的行。標題也算輸出的一行，15 行的巨集加一行標題是 16 行、要分成 2 個巨集。
- 行數只算到最後一個非空行：貼上的巨集結尾常帶幾個換行，不能因此多跳「超過 15 行」；空行在前面或中間照算，是巨集的一部分。
- 目標語言預設繁體中文、不看網站的介面語言；切換網站介面語言只換介面文字，不改目標語言，輸出也不動。
- 輸入、輸出框與目標語言選單都是 `autocomplete="off"`：瀏覽器重新整理時不會把輸入框還原成和輸出對不上的內容。
- 輸出框 `#outputMacro` 是這一頁的答案，不能看起來像提示字：共用的 `.form-control[readonly]` 把字設成輔助色（和提示字同色）、游標設成 `not-allowed`，`style.css` 只在輸出框蓋掉這兩樣。
- 「複製」沒有輸出時用 `aria-disabled="true"`，不用 `disabled`：按鈕變灰時焦點留在原地、鍵盤照樣 Tab 得到；`click` 照樣會送出，所以 `copyToClipboard()` 自己擋。
- `#copyOutput` 的 `min-width: 10.5em`：放得下三種語言裡最長的「✓ コピーしました」，「複製」換成「✓ 已複製」時按鈕不變寬、標題列不會在複製的那 2 秒換行（沒有這條時，日文在 360、375px 與英文在 390px 會換行，輸出框被推下約 34px）。只在 macOS 的 Chrome 量過。
- 「✓ 已複製」說的是剛才複製的那一份輸出：輸出變了就馬上變回「複製」。剪貼簿可能晚一點才寫完（瀏覽器在問權限），寫完時輸出已經變了，就只跳 toast「已複製」、按鈕不寫「✓ 已複製」（連按兩次而先按的最後才寫完時，剪貼簿換回的是舊的輸出）。
- 「貼上」讀到沒有字的剪貼簿（空字串、只有空白，例如複製的是圖片）時，和讀不到一樣，輸入框一個字都不動：沒有復原，不能把玩家已經有的字換成空的（刻意改的）。有字就整個換掉，不 trim。
- 貼上成功的朗讀 `#pasteAnnounce` 隔 100 毫秒才寫：區塊已經在頁面上才換字，螢幕閱讀器才會念（同 `FF14Utils.showToast`）。只在 macOS 的 Chrome 看過無障礙樹裡是 `status`，沒有用真的螢幕閱讀器聽過。
- 載入中的提示用 `position: absolute; inset: 0` 蓋在輸出框上、不占版面：以前它在工具最上面，每次打開頁面整個工具往下推約 100px 再彈回來。
- 「重試」在錯誤訊息裡，按下去錯誤訊息收起、按鈕跟著不見：按下去時焦點在它上面的話，載入完把焦點接住（成功移到輸入框、又失敗回到「重試」）；焦點不在它上面（Safari 與 macOS 的 Firefox 點按鈕不給焦點），或載入的期間玩家已經自己移到別的地方時，不去動焦點。
- 中文說明的 `word-break: keep-all` 只給 `:lang(zh)`：日文套了句號會單獨掉到下一行。
- 版面只在 macOS 的 Chrome 量過：390×844 的第一個畫面看得到輸出標題列與輸出的開頭（三種介面語言、有一條警告時也看得到），320px 寬沒有東西超出畫面。
