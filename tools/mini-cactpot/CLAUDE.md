# 仙人微彩計算機（tools/mini-cactpot/）

這裡只記讀程式碼看不出來的原因與陷阱。

- 期望值計算在不碰 DOM 的 `cactpot-solver.js`。同分要期望值差距小於 1e-6：浮點誤差會造成並列與門檻的邊界，畫面上寫成同一個數字的不一定同分。
- 狀態列留三行的高度（413px 以下的手機英文用 `:lang(en)` 留四行），換行時盤面不會跳動；只有 320px 寬、七個同分這種很少見的情況例外。
- 數字鍵 1–9 填進焦點所在的格子；小數字盤開在別格時先關掉它而不搶焦點：滑鼠打開後按 Tab 到另一格，Chrome 靠小選單自己關，Safari 點格子不給焦點，靠按鍵時關。按著 Ctrl／⌘／Alt、焦點不在格子上而小數字盤沒開、數字已經用了的按鍵都不 `preventDefault`，瀏覽器與系統的快速鍵照常。
