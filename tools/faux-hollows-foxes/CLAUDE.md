# 宗長計算機（tools/faux-hollows-foxes/）

這裡只記讀程式碼看不出來的原因與陷阱。

- 可能有宗長的格子只放 🦊、**不寫任何數字**：宗長多常出現沒有公開，算不出實際的機率；而拿盤面的比例當機率會騙人：「假設這局有宗長」的比例每翻開一個空格就往上加（只剩 1 種盤面時 25% → 33% → 50% → 100%），「可能有宗長的盤面占幾成」在劍確定後會讓 4 格同時寫 100%。宗長只在決定「④ 翻宗長」的下一格時，用「這格是還沒翻開的宗長位置的盤面種數」排先後；🦊 的說明留在頁面下方一句。
- 同分比的是「幾種盤面」這個整數，不除成比例再比。
- 自動補上的障礙物不存進狀態：每次重畫都從 36 格的狀態重新算，所以拿掉手動標的，它補上的跟著消失。
- 焦點所在的格子可能跟著鎖住（擺法確定時它是障礙物，或次數用完時它還沒翻）：`render()` 先記下焦點在哪一格，鎖住了就把焦點移到第一個下一格，沒有下一格就移到第一個能點的格子；不然瀏覽器會把焦點丟到頁面上，只用鍵盤就玩不下去。
- 「上一步」「重做」「重置遊戲」不能按時用 `aria-disabled`（焦點留在按鈕上），頁面上沒有 `.btn-primary`。
- 359px 以下提示字 11px，是這一頁唯一沒有用 token 的字級；只有一個提示的格子圖示一行、百分比一行，因為 `⚔️100%` 在手機上一行放不下。提示的寬度只在 macOS 的 Chrome 量過，Android、Safari、Firefox 沒有量過。
