# 天書奇談預測器（tools/wondrous-tails/）

這裡只記讀程式碼看不出來的原因與陷阱。

- 只寫機率、不給建議，也不用好壞配色：要不要重置由玩家決定。「重置之後」只在貼 3～7 張時有數字（遊戲只有這時能重置），其他張數寫「—」、長條長度 0。
- 連成的線上的格子框 3px 綠色 `outline`、只差一張的空格框 2px 綠色虛線 `border`，已貼的格子也不設 `box-shadow`：共用的 `.cell:focus-visible` 焦點外框才不會被蓋掉（用鍵盤時看得到焦點在哪一格）。
- 「清空盤面」與「復原」是同一顆按鈕：清空時先存一份清空前的盤面；清空之後真的貼上或拿掉任何一張貼紙就不能再復原（被 `toggle()` 擋下來的點擊不算）。
