# 角色卡產生器（tools/character-card/）

做一張冒險者自介卡，成品是一張 PNG。三種風格（A 名片、B 海報（預設）、C 資訊卡）用同一份資料。這裡只記讀程式碼看不出來的原因、瀏覽器的坑與已知限制。

## 為什麼這樣做

- 卡片由程式畫在一個 `<canvas>` 上，畫面上的預覽就是同一張 canvas 用 CSS 縮小顯示（圓角是 CSS 加的，PNG 是整張矩形），下載、分享、複製的是它轉出來的 PNG；不用 `html2canvas` 之類的轉圖套件。
- 怎麼畫分三層：`card-paint.js`（三種風格共用的小工具）、`card-style-a.js`／`card-style-b.js`／`card-style-c.js`（一種風格一支）、`card-renderer.js`（照 `model.style` 交給那一種風格畫）。都只畫圖、不碰 DOM、收任何 2D context，也不用 `ctx.filter` 與 `ctx.letterSpacing`（舊的 Safari 沒有），字距一個字素一個字素畫。每種風格自己的顏色與版面數字（照草稿，單位是 cqw：卡片寬度的 1%）只寫在自己的檔案裡，改一種不會動到另一種；`card-paint.js` 不放任何一種風格自己的顏色與數字，例外是預設背景，與名片、資訊卡共用的排法用到的四個數字。
- 名片的模糊背景：草稿是 CSS 的 `blur(2.6cqw)`，但舊的 Safari 沒有 `ctx.filter`、畫圖程式又不碰 DOM，所以頁面在上傳與還原截圖時用 `CardImage.blur()` 把截圖照 cover 放到卡片大小、一路減半縮成很小的圖、再放大 4 倍畫進一張小 canvas（瀏覽器的縮放補出平滑的漸層，看起來就是模糊），橫版與直版各做一張，再壓一層 `rgba(0,0,0,0.58)`（草稿的 `brightness(0.42)`，飽和度的 1.25 不做）。放大後任何一邊會超過 4096 像素就不做、改畫預設背景：瀏覽器不肯給太大的 canvas，畫出來是透明的。和草稿的 CSS 模糊逐像素比，均方根差不到 1（0～255），只在 macOS 的 Chrome 量過，Safari、Firefox 沒量過。
- 卡片上「一個字」的單位是字素（`CardLayout.graphemes()` 用 `Intl.Segmenter`：國旗、家庭 emoji、加膚色的 emoji、鍵帽、e 加重音符號都是一個）：字距、折行、行首禁用、從長單字裡斷、結尾接「…」、取職業名稱的第一個字都以字素為單位，不會把國旗拆成兩半或讓重音符號掉到行首。沒有 `Intl.Segmenter` 的舊瀏覽器（Firefox 125 以前）退回以 Unicode 字元為單位。
- 字數上限以 Unicode 字元計（一面國旗算 2 個），和欄位旁的計數一樣。欄位不用 `maxlength`：每次輸入後用 `CardState.fitInput()` 照同一個上限檢查，只拿掉這次打進來、放不下的字（照整段新字的字素，從前面放到放不下為止，前後原本的字不動，游標放回打字的地方），所以計數到上限就是真的滿了，國旗不會只剩一半。換掉的是哪一段照改之前的選取：頁面在 `beforeinput`（打字、貼上）與 `compositionstart` 記下那時的選取，全選再貼上就是換掉選取的字、不是在前面插入；沒有這兩個事件的改動（例如自動填入）與拖放、復原只看前後兩段字比對。輸入法組字中不改欄位的字（卡片與記住的資料用放得下的字），選完字（`compositionend`）才檢查，`change` 再檢查一次。
- 字型：中文字型依字分批載入，沒載到的字會退成備用字型，所以每畫一次就請瀏覽器載入還沒請求過的字，載完重畫。下載、分享、複製前等字型、職業圖示與還原中、上傳中的角色圖都好了才產生，最多等 10 秒（`EXPORT_WAIT_MS`）：卡住的請求不能讓按鈕永遠沒反應，逾時就照目前的畫面產生並跳 toast。
- 對比度：每一段字和它的底都至少 4.5:1（WCAG），包括很淺的自己選的重點色；稱號與膠囊的字用 `CardPaint.readableOn()` 把重點色往深色調到剛好夠。唯一的例外是沒有圖示的職業畫在重點色方塊裡的大字：`CardLayout.textColorOn()` 在白字與深字裡挑，最差的重點色上約 4.2:1，但它一定是 18.67px（14pt）以上的粗體，WCAG 的大字只要 3:1。
- 第一次上線存的資料（`style: 'b'`、只有 `b-landscape`、`b-portrait` 兩份圖片位置，`v: 1`）不需要轉換、照用：改儲存格式時不能弄壞它。
- 圖片和欄位分開存（`ff14tw_character_card_image`）：圖片存不進去（容量已滿）時文字欄位才照樣記得住；那時也把以前存的那張圖拿掉，不然重新整理後會冒出已經換掉的舊圖。
- 手機上手指從卡片上滑要能捲動頁面，所以觸控為主的裝置要先按「調整圖片」才拖得動。「左右」「上下」兩個位置滑桿是不能拖曳的人（鍵盤、單指點一下，WCAG 2.5.7）移動圖片的另一個做法。

## 瀏覽器的坑

- 轉 JPEG 用的暫存 canvas 用完（失敗也一樣）就把寬高設成 0 放掉：iOS Safari 的 canvas 記憶體有總量上限，一個 session 裡傳很多張圖都不放，之後就轉不出圖。
- `navigator.share` 只在點擊之後的幾秒內有效：等字型、等圖太久，點擊的使用者手勢就過期了（`NotAllowedError`），這時改開全螢幕大圖、焦點放在大圖的「分享」並請玩家再按一次（大圖裡分享的是已經做好的檔案，一按就呼叫）。
- 複製圖片：Safari 要求在使用者手勢裡寫剪貼簿，所以點擊的當下就把還沒做好的圖（Promise）交給 `ClipboardItem` 並呼叫 `clipboard.write`。
- 下載：`<a download>` 要先接到文件上再點（Firefox 對沒接在文件上的連結不理）；`blob:` 網址不在同一個 tick 撤銷，等 `CardExport.REVOKE_DELAY_MS`：有的瀏覽器網址一撤銷就取消這次下載。
- Safari 藏起有焦點的欄位時不一定送 `focusout`：手機版面換分頁時，`selectTab()` 先讓它失去焦點並拿掉 `.is-typing`。
- 選單（`<select>`）不算打字：它不開鍵盤，Android 與電腦的 Chrome 選完之後焦點還留在選單上，算的話選完主職，手機的按鈕列會一直收著。
- LINE 的內建瀏覽器與手機的瀏覽器不共用這個網站記住的資料：填好才換瀏覽器會什麼都不在，所以提示（連結加 `?openExternalBrowser=1`）請玩家在填之前就換。

## 版面

- 兩欄版面 `(min-width: 769px), (min-width: 560px) and (max-height: 500px)`（電腦，與橫放的小手機）和手機版面 `(max-width: 559px), (max-width: 768px) and (min-height: 501px)`（`script.js` 的 `PHONE_QUERY`，和 `style.css` 手機那一塊 `@media` 是同一個字串）對整數像素的畫面大小剛好互補；瀏覽器縮放量出的小數大小（例如 559.5×400、768.5×600、600×500.5）可能兩個都不符合，和全站其他 768／769 的界線一樣，不處理。
- 橫放的小手機只在 macOS 的 Chrome（手機模擬）量過，Android、iOS 的真機與 Safari、Firefox 沒量過：667×375、740×360、568×320 是兩欄、沒有左右捲，預覽欄貼在畫面上緣時整欄（卡片、「橫版／直版」、下載等按鈕）橫版與直版都在畫面內；844×390 和改版前逐項一樣。
- 名片直版在名字短、其他區塊都到最高時，區塊之間的間距從 20.52px 縮成 19.87px（`card-style-a.js` 的開頭與 `tests/character-card-style-a.test.js` 寫的是同一個數字，改了要一起改）。

## 已知的限制（都沒處理）

- 手機瀏覽器的網址列顯示時，`100vh` 比看得到的高度高 40～50px，直版預覽欄的第二排按鈕（分享、複製圖片）可能被切到，第一排的下載鈕還看得到。
- 英文介面在寬 560～566px 時，「橫版／直版」兩顆按鈕放不下一排而換行，整欄比算出來的多約 40px，下載鈕還看得到。
- LINE 的提示（`#lineTip`）顯示時整欄多約 45px，提示的第二行可能被切到，按鈕都還看得到。
- 寬 769～843px、高 500px 以下（例如 800×360 的手機橫放）照舊用兩欄版面的 `70vh`：中文的直版按鈕一排放得進，英文、日文的直版按鈕要兩排，第二排（分享、複製圖片）會超出畫面，下載鈕還看得到。
- 矮的橫向畫面那一塊（寬 560～768、高 500 以下）的卡片高度上限是 `100vh - 168px`，畫面高度在 168px 以下時上限是 0、卡片看不到（例如鍵盤打開時會把版面變矮的瀏覽器；Android 的 Chrome 預設不會）。
- 被字數上限截掉之後，那一格的復原（⌘Z／Ctrl+Z）沒有作用：程式改了欄位的字，Chrome 的復原紀錄就用不了。
- 沒有 `beforeinput` 的改動（例如自動填入）與拖放、復原只看前後兩段字，選取一段字之後放進來的字開頭或結尾和原本的字一樣時，可能當成在前面或後面插入而放不下。
- 輸入法組字中欄位的字與計數可能暫時超過上限（卡片與記住的資料是放得下的字），選完字才收回來。
- 把國旗拆成兩個字母分兩次打時（一般的鍵盤與 emoji 選單不會這樣），第二個字母放不下就留下半面國旗。
- 沒有 `Intl.Segmenter` 的舊瀏覽器照 Unicode 字元切。
- 輸入法只用測試替身照假設的事件順序測過，沒有實機試過。
- 別的平台的 emoji 寬度沒量過，名字放 21 個 1.3 倍寬的 emoji 放得下是測試用的假設。
- 回到頂部鈕（fixed 在右下）會蓋住預覽欄右下角一小塊（568×320 的英文介面約 8px，蓋到「複製圖片」的角；844×390 本來就有同樣的重疊）。
