# 陸行鳥染色計算器（tools/chocobo-color/）

這裡只記讀程式碼看不出來的原因與限制。

- 配方（要餵哪幾種水果、各幾顆）的規則沿用舊的計算器，沒有改；這個工具改的是怎麼分段、照什麼順序餵。
- 「直接調色」和「先餵 1 顆拉札漢檸檬（變回沙漠黃）再從沙漠黃調色」一樣多顆時用檸檬：從確定的沙漠黃開始比較準。
- 顏色資料參考自 ffxivchocobo.com（頁面上有標示）。色票與水果色點的顏色是資料，由 JS 設定 `style.background`，`style.css` 裡沒有色碼。
- 480px 以下兩顆顏色按鈕上下排成兩列、頁首下的說明視覺上隱藏（螢幕閱讀器仍讀得到）：為了讓 390×844 的手機第一個畫面放得下總顆數與每一段。沒有自動測試守住，改版面要用瀏覽器量。
